# Смородина
Демонстрационный магазин украшений на React, TypeScript и Vite. Главная, каталог и корзина открыты всем. Для оформления требуется демоаккаунт.

## Запуск
Из корня проекта выполните `docker compose up --build` и откройте http://127.0.0.1:5173. Для отдельного запуска витрины с Node.js 24 выполните в папке frontend:
```sh
npm ci
npm run dev
```
Проверки: `npm run lint`, `npm test`, `npm run build`. Последняя команда проверяет типы и создаёт dist. Стартовые проверки стека описаны в TESTS.md в корне.

## Попробовать заказ
1. В каталоге выберите цвет или категорию. Откройте изделие, укажите размер и пожелания, добавьте его в корзину.
2. Перейдите к оформлению, нажмите «Зарегистрироваться», введите вымышленный телефон. Шестизначный демонстрационный код показан на экране. Заполните имя и примите условия. При повторном входе используйте тот же номер.
3. Выберите тестовый адрес выдачи, способ связи и демооплату. Проверьте состав заказа. Можно сначала проверить отказ, затем подтвердить оплату. Номер и состав заказа появятся в кабинете.
4. Ссылка «Демо мастерской» внизу страницы открывает редактор цен, изображений, характеристик и наличия и журнал заказов для Елены. У каждого заказа сохранён снимок позиций и контактов.

## Данные и интеграции
Одинаковая маска телефона при входе и оформлении: `+7(XXX)-XXX-XX-XX`. Код можно вставить сразу целиком в первую из шести ячеек. Повторный запрос доступен через минуту, три ошибки блокируют ввод на минуту. В мастерской можно отметить заказ готовым к выдаче: покупатель увидит уведомление и адрес ПВЗ в своём кабинете в этом же браузере.

15 тестовых изделий с оригинальными векторными иллюстрациями. Фото по URL и свойства меняются в мастерской. Исходный ассортимент и интерфейсы SMS, доставки, оплаты и уведомлений находятся в src/shop.ts. Подборки используют тип и цвет изделия.

Это однопользовательский локальный прототип. Данные сохраняются в localStorage браузера, проверочный код и таймер в sessionStorage. Мастерская открыта участникам демонстрации. Используйте только вымышленные контакты. Все адреса ПВЗ тестовые, SMS и уведомления ВКонтакте имитируются, деньги не списываются.

Для реальных продаж потребуются серверное хранение и проверка цен и остатков, разграничение прав, серверная авторизация и лимиты SMS, провайдеры доставки и платежей с проверкой webhook и идемпотентностью заказа, защищённая отправка уведомлений ВКонтакте. Владелице нужно заменить ассортимент и фото, заполнить условия продажи и проверить юридические документы.
